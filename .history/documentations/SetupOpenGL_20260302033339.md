# OpenGL Setup Guide - Complete Documentation

## The Construction Site Analogy

Setting up OpenGL is like preparing a construction site before building a house:

- **The Land** = Your computer's graphics hardware (GPU)
- **Building Permits** = Graphics drivers (must be installed)
- **Architect's Plans** = OpenGL specification (the rules)
- **Construction Crew** = Your code (using OpenGL functions)
- **Temporary Structures** = GLFW/SDL (window and context creation)
- **Tool Shed** = GLAD/GLEW (function pointer loading)

**You can't just start building - you need permits, tools, and a clear plan. OpenGL setup follows the same principle.**

---

## Part 1: Understanding What OpenGL Setup Entails

### What You're Actually Setting Up

```
YOUR APPLICATION
    ↓
[ OPENGL FUNCTIONS ] ←── These need to be loaded
    ↓
[ GRAPHICS DRIVER ] ←── Must be installed
    ↓
[ GPU HARDWARE ]
```

### The Three Essential Components

| Component | Purpose | Who Provides It |
|-----------|---------|-----------------|
| **Graphics Driver** | GPU communication | NVIDIA/AMD/Intel |
| **Window/Context** | Render target & OpenGL context | GLFW, SDL, or platform code |
| **Function Loader** | OpenGL function addresses | GLAD, GLEW, or manual loading |

### Why Setup Is Not Trivial

```cpp
// You CANNOT do this on Windows/Linux:
glDrawArrays(GL_TRIANGLES, 0, 3);  // This will crash!

// Why? Because OpenGL functions are not automatically linked
// They must be loaded from the driver at runtime
```

## Part 5: GLAD - OpenGL Function Loader

### What is GLAD?

**GLAD** generates code that loads OpenGL function pointers from your driver. It's the modern recommended loader.

### Using the GLAD Web Service

```
1. Go to https://glad.dav1d.de/
2. Configure:
   ├─ Language: C/C++
   ├─ Specification: OpenGL
   ├─ API: gl (Version: 3.3 or 4.6)
   ├─ Profile: Core
   └─ Options: Generate a loader
3. Click GENERATE
4. Download the generated ZIP file
5. Extract into your project:
   ├─ include/glad/glad.h
   ├─ include/KHR/khrplatform.h
   └─ src/glad.c
```

### Manual GLAD Configuration

```cpp
// glad.h contains:
typedef void (*GLADloadproc)(const char* name);

// Core function declarations
GLAPI int gladLoadGL(void);  // For OpenGL
GLAPI int gladLoadGLLoader(GLADloadproc);  // Custom loader
```

### Including GLAD in Your Code

```cpp
// MUST be included before any other OpenGL headers
#include <glad/glad.h>

// Then include GLFW (or other window library)
#include <GLFW/glfw3.h>

// NEVER include gl.h directly!
```

## Part 6: GLFW - Window and Context Creation

### What is GLFW?

**GLFW** creates windows, handles input, and manages the OpenGL context.

### Installing GLFW

**Option A: Download Binaries**
```
1. Go to https://www.glfw.org/download.html
2. Download pre-compiled binaries for your platform
3. Extract to your project:
   ├─ include/GLFW/glfw3.h
   └─ lib/glfw3.lib (Windows) or libglfw3.a (Linux/macOS)
```

**Option B: Using vcpkg**
```bash
vcpkg install glfw3
```

**Option C: Using CMake (FetchContent)**
```cmake
include(FetchContent)
FetchContent_Declare(
    glfw
    GIT_REPOSITORY https://github.com/glfw/glfw.git
    GIT_TAG 3.3.8
)
FetchContent_MakeAvailable(glfw)
```

**Option D: Package Managers (Linux)**
```bash
sudo apt install libglfw3-dev        # Ubuntu/Debian
sudo dnf install glfw-devel          # Fedora
sudo pacman -S glfw                  # Arch
```

### GLFW Initialization Pattern

```cpp
// Always follow this pattern:
if (!glfwInit()) {
    // Handle error
    return -1;
}

// Configure GLFW
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
#ifdef __APPLE__
    glfwWindowHint(GLFW_OPENGL_FORWARD_COMPAT, GL_TRUE);
#endif

// Create window
GLFWwindow* window = glfwCreateWindow(800, 600, "OpenGL Window", NULL, NULL);
if (!window) {
    glfwTerminate();
    return -1;
}

// Make context current
glfwMakeContextCurrent(window);

// Set callback functions
glfwSetFramebufferSizeCallback(window, framebuffer_size_callback);
glfwSetKeyCallback(window, key_callback);
```

## Part 7: Complete Setup Code Walkthrough

### Step 1: Include Headers

```cpp
// main.cpp
#include <iostream>

// GLAD must be included before GLFW
#include <glad/glad.h>
#include <GLFW/glfw3.h>

// Optional but recommended
#include <glm/glm.hpp>
#include <glm/gtc/matrix_transform.hpp>
#include <glm/gtc/type_ptr.hpp>

// Callback function declarations
void framebuffer_size_callback(GLFWwindow* window, int width, int height);
void processInput(GLFWwindow* window);
```

### Step 2: Initialize GLFW and Create Window

```cpp
int main() {
    // Initialize GLFW
    if (!glfwInit()) {
        std::cerr << "Failed to initialize GLFW" << std::endl;
        return -1;
    }
    
    // Configure OpenGL version
    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
    glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
    
    // Create window
    GLFWwindow* window = glfwCreateWindow(800, 600, 
                                          "OpenGL Setup Demo", 
                                          NULL, NULL);
    if (!window) {
        std::cerr << "Failed to create GLFW window" << std::endl;
        glfwTerminate();
        return -1;
    }
    
    // Make the OpenGL context current
    glfwMakeContextCurrent(window);
    
    // Set callback for window resize
    glfwSetFramebufferSizeCallback(window, framebuffer_size_callback);
```

### Step 3: Load OpenGL Functions with GLAD

```cpp
    // Load OpenGL function pointers
    if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress)) {
        std::cerr << "Failed to initialize GLAD" << std::endl;
        return -1;
    }
    
    // Now OpenGL functions are available!
    std::cout << "OpenGL Version: " << glGetString(GL_VERSION) << std::endl;
    std::cout << "GLSL Version: " << glGetString(GL_SHADING_LANGUAGE_VERSION) << std::endl;
    std::cout << "Renderer: " << glGetString(GL_RENDERER) << std::endl;
    std::cout << "Vendor: " << glGetString(GL_VENDOR) << std::endl;
```

### Step 4: Configure OpenGL Global State

```cpp
    // Set viewport
    glViewport(0, 0, 800, 600);
    
    // Enable depth testing
    glEnable(GL_DEPTH_TEST);
    glDepthFunc(GL_LESS);
    
    // Enable face culling
    glEnable(GL_CULL_FACE);
    glCullFace(GL_BACK);
    glFrontFace(GL_CCW);
    
    // Set clear color
    glClearColor(0.2f, 0.3f, 0.3f, 1.0f);
```

### Step 5: Create and Compile Shaders

```cpp
    // Vertex shader source
    const char* vertexShaderSource = R"(
        #version 330 core
        layout (location = 0) in vec3 aPos;
        
        void main() {
            gl_Position = vec4(aPos, 1.0);
        }
    )";
    
    // Fragment shader source
    const char* fragmentShaderSource = R"(
        #version 330 core
        out vec4 FragColor;
        
        void main() {
            FragColor = vec4(1.0, 0.5, 0.2, 1.0);
        }
    )";
    
    // Compile vertex shader
    unsigned int vertexShader = glCreateShader(GL_VERTEX_SHADER);
    glShaderSource(vertexShader, 1, &vertexShaderSource, NULL);
    glCompileShader(vertexShader);
    
    // Check compilation
    int success;
    char infoLog[512];
    glGetShaderiv(vertexShader, GL_COMPILE_STATUS, &success);
    if (!success) {
        glGetShaderInfoLog(vertexShader, 512, NULL, infoLog);
        std::cerr << "Vertex shader compilation failed:\n" << infoLog << std::endl;
    }
    
    // Compile fragment shader
    unsigned int fragmentShader = glCreateShader(GL_FRAGMENT_SHADER);
    glShaderSource(fragmentShader, 1, &fragmentShaderSource, NULL);
    glCompileShader(fragmentShader);
    
    // Link shader program
    unsigned int shaderProgram = glCreateProgram();
    glAttachShader(shaderProgram, vertexShader);
    glAttachShader(shaderProgram, fragmentShader);
    glLinkProgram(shaderProgram);
    
    // Clean up shader objects
    glDeleteShader(vertexShader);
    glDeleteShader(fragmentShader);
```

### Step 6: Create Vertex Data and Buffers

```cpp
    // Vertex data for a triangle
    float vertices[] = {
        -0.5f, -0.5f, 0.0f,
         0.5f, -0.5f, 0.0f,
         0.0f,  0.5f, 0.0f
    };
    
    // Create VAO, VBO
    unsigned int VAO, VBO;
    glGenVertexArrays(1, &VAO);
    glGenBuffers(1, &VBO);
    
    // Bind and configure
    glBindVertexArray(VAO);
    
    glBindBuffer(GL_ARRAY_BUFFER, VBO);
    glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
    
    glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), (void*)0);
    glEnableVertexAttribArray(0);
    
    // Unbind (optional)
    glBindBuffer(GL_ARRAY_BUFFER, 0);
    glBindVertexArray(0);
```

### Step 7: Render Loop

```cpp
    // Render loop
    while (!glfwWindowShouldClose(window)) {
        // Input
        processInput(window);
        
        // Clear buffers
        glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
        
        // Draw triangle
        glUseProgram(shaderProgram);
        glBindVertexArray(VAO);
        glDrawArrays(GL_TRIANGLES, 0, 3);
        
        // Swap buffers and poll events
        glfwSwapBuffers(window);
        glfwPollEvents();
    }
```

### Step 8: Cleanup

```cpp
    // Cleanup
    glDeleteVertexArrays(1, &VAO);
    glDeleteBuffers(1, &VBO);
    glDeleteProgram(shaderProgram);
    
    glfwDestroyWindow(window);
    glfwTerminate();
    return 0;
}

// Callback implementations
void framebuffer_size_callback(GLFWwindow* window, int width, int height) {
    glViewport(0, 0, width, height);
}

void processInput(GLFWwindow* window) {
    if (glfwGetKey(window, GLFW_KEY_ESCAPE) == GLFW_PRESS)
        glfwSetWindowShouldClose(window, true);
}
```

## Part 9: Platform-Specific Issues and Solutions

### Windows Common Issues

```cpp
// ERROR: LNK2019: unresolved external symbol
// Cause: Missing library in linker settings
// Fix: Add opengl32.lib to linker input

// ERROR: GLFW can't create OpenGL context
// Cause: Wrong OpenGL version requested
// Fix: 
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);

// ERROR: gl.h already included
// Cause: Including gl.h before glad
// Fix: Include glad.h first, never include gl.h
```

### Linux Common Issues

```cpp
// ERROR: undefined reference to `gladLoadGLLoader'
// Cause: glad.c not compiled
// Fix: Add glad.c to your source files

// ERROR: cannot find -lglfw
// Cause: GLFW development package not installed
// Fix: sudo apt install libglfw3-dev

// ERROR: OpenGL version < 3.3
// Cause: Mesa drivers too old
// Fix: Update drivers or use software rendering:
export MESA_GL_VERSION_OVERRIDE=3.3
```

### macOS Common Issues

```cpp
// ERROR: glfwWindowHint(GLFW_OPENGL_PROFILE, ...) causes crash
// Cause: macOS requires forward compatibility
// Fix:
#ifdef __APPLE__
    glfwWindowHint(GLFW_OPENGL_FORWARD_COMPAT, GL_TRUE);
#endif

// ERROR: OpenGL 4.6 not available
// Cause: macOS only supports up to 4.1
// Fix: Use OpenGL 4.1 or consider MoltenVK for Vulkan

// ERROR: Retina display scaling issues
// Fix: Get framebuffer size, not window size
int fbWidth, fbHeight;
glfwGetFramebufferSize(window, &fbWidth, &fbHeight);
glViewport(0, 0, fbWidth, fbHeight);
```

## Part 10: Error Handling and Debugging

### GLFW Error Callback

```cpp
// Set up GLFW error callback early
void glfw_error_callback(int error, const char* description) {
    std::cerr << "GLFW Error " << error << ": " << description << std::endl;
}

// In main():
glfwSetErrorCallback(glfw_error_callback);
```

### OpenGL Error Checking

```cpp
// Utility function to check OpenGL errors
bool checkOpenGLError(const char* file, int line) {
    GLenum error;
    bool hasError = false;
    while ((error = glGetError()) != GL_NO_ERROR) {
        std::cerr << "OpenGL Error (" << file << ":" << line << "): ";
        switch (error) {
            case GL_INVALID_ENUM: std::cerr << "GL_INVALID_ENUM"; break;
            case GL_INVALID_VALUE: std::cerr << "GL_INVALID_VALUE"; break;
            case GL_INVALID_OPERATION: std::cerr << "GL_INVALID_OPERATION"; break;
            case GL_OUT_OF_MEMORY: std::cerr << "GL_OUT_OF_MEMORY"; break;
            default: std::cerr << "0x" << std::hex << error;
        }
        std::cerr << std::endl;
        hasError = true;
    }
    return hasError;
}

// Use it like this:
#define glCheck(x) x; checkOpenGLError(__FILE__, __LINE__)

// Then:
glCheck(glDrawArrays(GL_TRIANGLES, 0, 3));
```

### Debug Output (OpenGL 4.3+)

```cpp
// Enable debug output
void GLAPIENTRY debugCallback(GLenum source, GLenum type, GLuint id,

                              const GLchar* message, const void* userParam) {
```

## Part 11: Quick Start Templates

### Minimal Working Example

```cpp
// minimal_opengl.cpp
#include <iostream>
#include <glad/glad.h>
#include <GLFW/glfw3.h>

void framebuffer_size_callback(GLFWwindow* window, int width, int height) {
    glViewport(0, 0, width, height);
}

int main() {
    // Initialize GLFW
    if (!glfwInit()) {
        std::cerr << "Failed to initialize GLFW" << std::endl;
        return -1;
    }
    
    // Configure OpenGL
    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
    glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
    
    // Create window
    GLFWwindow* window = glfwCreateWindow(800, 600, "OpenGL Demo", NULL, NULL);
    if (!window) {
        std::cerr << "Failed to create window" << std::endl;
        glfwTerminate();
        return -1;
    }
    
    glfwMakeContextCurrent(window);
    glfwSetFramebufferSizeCallback(window, framebuffer_size_callback);
    
    // Load OpenGL functions
    if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress)) {
        std::cerr << "Failed to initialize GLAD" << std::endl;
        return -1;
    }
    
    // Print version info
    std::cout << "OpenGL " << glGetString(GL_VERSION) << std::endl;
    
    // Set clear color
    glClearColor(0.2f, 0.3f, 0.3f, 1.0f);
    
    // Render loop
    while (!glfwWindowShouldClose(window)) {
        glClear(GL_COLOR_BUFFER_BIT);
        
        glfwSwapBuffers(window);
        glfwPollEvents();
    }
    
    glfwDestroyWindow(window);
    glfwTerminate();
    return 0;
}
```

## Part 12: Troubleshooting Checklist

### Setup Verification Steps

```cpp
// 1. Check GLFW initialization
if (!glfwInit()) { /* error */ }

// 2. Check window creation
GLFWwindow* window = glfwCreateWindow(...);
if (!window) { /* error */ }

// 3. Check GLAD initialization
if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress)) { /* error */ }

// 4. Print version info
const GLubyte* version = glGetString(GL_VERSION);
if (!version) { 
    std::cerr << "OpenGL not initialized!" << std::endl;
}
```

### Common Errors and Solutions

| Error | Likely Cause | Solution |
|-------|--------------|----------|
| **Window creation fails** | Wrong OpenGL version requested | Lower version or check driver support |
| **gladLoadGLLoader fails** | GLFW context not current | Call `glfwMakeContextCurrent` before loading |
| **glGenVertexArrays crashes** | OpenGL version < 3.0 or no context | Check OpenGL version and context creation |
| **Black screen** | No clear or draw calls | Check render loop and clear flags |
| **Segmentation fault** | NULL pointer or unloaded function | Check all pointers and GLAD initialization |
| **Linker errors** | Missing libraries | Add required libraries to linker |
| **Texture not showing** | UV coordinates or texture setup | Verify texture coordinates and binding |

## The 30-Second Summary

- **Prerequisites** = Graphics driver, C++ compiler, build system
- **Essential Libraries** = GLFW (window/context) + GLAD (function loader)
- **Setup Order** = GLFW init → Window creation → Context current → GLAD load
- **Version Selection** = OpenGL 3.3 Core Profile (best for learning)
- **Build Integration** = Include GLAD source, link GLFW and OpenGL libraries
- **Verification** = Check all return values, print version info
- **Common Pitfalls** = Wrong include order, missing context, incorrect library linking

**Proper OpenGL setup is the hardest part of learning - once you see that colored window, the worst is behind you!**
